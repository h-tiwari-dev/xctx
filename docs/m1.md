# Milestone 1: build xctx inside xctx

**Status:** Complete (all 4 waves implemented, reviewed, and hardened). Next up: [`docs/m2.md`](m2.md).

The milestone is done when xctx can be developed in xctx: a day of work on this repo, with `pi` agents, without
going back to another terminal or multiplexer.

## What a user can do at the end of it

1. Open the app and see **Home**: the living spaces, and one prompt.
2. Type a task. xctx drafts a space: the repos it found under the indexed folders, with the reason for each, and the
   user can add or drop repos. Nothing runs until **Launch**.
3. Launch. For each repo, xctx makes a worktree on branch `space/<slug>` and a git-ignored `mise.<slug>.toml` with the
   space's own `PORT`, then opens the space as a tab with an agent terminal (`pi`, given the task) and a shell per
   repo, running in the worktree with `MISE_ENV=<slug>`.
4. Work in the panes: split, close, move focus, resize, zoom. The terminal is good enough to run `pi`, `nvim` and
   `lazygit` all day: truecolor, scrollback, selection and copy, paste, mouse, and the keys agent TUIs depend on
   (Shift+Enter, Alt and Ctrl chords).
5. Switch between spaces and reshape one (dev, debug, review) without losing its agents.
6. Quit and reopen: spaces, their worktrees and their layouts are back, and agents can be resumed.
7. **Ship** a space (push, open a PR where there are new commits and a remote, remove the worktrees) or **Discard** it
   (remove the worktrees, keep the branches).

## Not in this milestone

The parent agent, orchestrators, the contract and channel, the agent graph view, the inbox, loops and autonomy
levels, plugins other than the terminal, and the harness control socket that lets agents drive the window. The
control socket is the first thing in milestone 2.

## Crates

| Crate | GPUI | Owns |
| --- | --- | --- |
| `xctx-core` | no | git and worktrees, the repo index, the space model and lifecycle, the per-space mise file, the store on disk |
| `xctx-layout` | no | the pane tree: split, close, focus, resize, zoom, rectangles, shape presets |
| `xctx-term` | no | a terminal session: PTY, emulation, grid snapshots, input encoding, selection |
| `xctx-term-view` | yes | draws an `xctx-term` session and feeds it keys, mouse and resize |
| `xctx-ui` | yes | tab bar, split view over an `xctx-layout` tree, prompt, status bar, theme |
| `xctx` | yes | the app: Home, the draft and launch flow, spaces as tabs, persistence, ship and discard |

## Waves

1. **Foundations, in parallel:** `xctx-core`, `xctx-layout`, `xctx-term`, and moving the app to the pinned GPUI from
   the Zed repository. Each is its own branch and worktree off `m1-base`.
2. **Views, in parallel:** `xctx-term-view` and `xctx-ui`, on top of wave 1.
3. **Integration:** the app, in one lane.
4. **Dogfood hardening:** review, then fix what a day of real use turns up.
